## Stream Dock LIVE icons · C4 Neon Edge

Пак кнопок под **Live Mode**: место под цифры W/L и короткий код ранга.

### Состав
- 48 скинов × 17 кнопок (144×144)
- Превью: `_sheet_<skin>.png`
- Win/Loss ±1, Rank ↑↓, Reset, Game/Mode/Role, Show, rank по ролям

### Установка
1. Распакуйте zip
2. Откройте папку скина (как в виджете), например `default/`
3. Назначьте PNG на кнопки Stream Dock
4. Плагин v1.1.0+ → Live Mode ON

Инструкция: https://github.com/ARTJ1/OBS-Stream-Widget-Statistics-v2/blob/main/docs/STREAMDOCK-LIVE.md

Плагин: https://github.com/ARTJ1/streamdock-http-request/releases
