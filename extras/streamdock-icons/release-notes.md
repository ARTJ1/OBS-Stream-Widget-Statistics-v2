## Stream Dock / AJAZZ button icons

Готовые **144×144** PNG под **все 48 скинов** виджета.

Плагин HTTP для AJAZZ остаётся без картинок: https://github.com/ARTJ1/streamdock-http-request

### Что внутри zip
- Папка на каждый skin id (`default`, `cyber-cyan`, `sakura-dusk`, …)
- 15 кнопок: win, loss, rank↑/↓, reset, game/mode/role next, rank по ролям, show
- `_sheet_<skin>.png` — превью всего набора

### Как пользоваться
1. Скачайте `streamdock-icons-v1.0.0.zip`
2. Выберите папку скина как в админке виджета
3. Поставьте PNG на кнопки Stream Dock / AJAZZ
4. URL: `http://127.0.0.1:19123/api/...`

Генератор в репозитории: `extras/streamdock-icons/`
