# v2.8.0 — автоматический ранг (альфа)

- Новый переключатель «Автоматический ранг» (альфа) в разделе автозачёта: после соревновательного матча виджет сам читает роль и ранг с экрана прогресса («УРОН — ИЗУМРУД 2», «DAMAGE — EMERALD 3») и обновляет ранг
- В режимах по ролям ранг меняется у той роли, на которой вы играли, даже если в виджете выбрана другая; виджет переключается на эту роль
- В режиме «отдельный счёт по ролям» победа или поражение тоже переносится на сыгранную роль
- Ранг читается целиком, а не как +1/−1: если какой-то матч пропущен, следующий матч всё поправит
- Работает вместе с автозачётом побед, по умолчанию выключено. Если сразу выйти из матча, игра не показывает экран прогресса, и ранг не меняется

Для обновления замените widget-stats.exe и widget_control.lua.
