# v3.1.3 — обновления надёжнее и понятнее

Обновление не зависит от названия папки и показывает, что происходит

### Что нового

- **Исправлено:** после обновления виджет мог не запуститься, если в пути к его папке есть русские буквы, & или %. Теперь подходит папка с любым названием
- **Видно, что происходит.** Карточка обновления показывает, сколько уже скачано, и шаги: скачивание, проверка, перезапуск
- **Понятные ошибки.** Если обновить не вышло, виджет напишет почему и что делать. В большинстве случаев он просто продолжит работать на прежней версии
- Новая версия сначала проверяется запуском, и только потом заменяет старую
- Зависшее скачивание больше не висит минутами: если данные не приходят 30 секунд, виджет пробует заново

### Что будет при обновлении

- Настройки, счёт, ранг и свои скины сохранятся
- Около минуты: виджет перезапустится, страница обновится сама
- **Только в этот раз:** если в пути к папке виджета есть русские буквы, & или %, он может не запуститься сам. Тогда скачайте widget-stats.exe с GitHub и замените им старый файл. Настройки сохранятся, а следующие обновления пройдут сами

## English

Updating no longer depends on the folder name and shows what is going on

### What's new

- **Fixed:** the widget could fail to start after an update if the path to its folder had non-Latin letters, & or %. Any folder name works now
- **You can see what is going on.** The update card shows how much is downloaded and the steps: download, check, restart
- **Clear errors.** If an update fails, the widget says why and what to do. In most cases it simply keeps running on the previous version
- The new version is test-started first and only then replaces the old one
- A stuck download no longer hangs for minutes: if no data arrives for 30 seconds, the widget tries again

### What happens when you update

- Your settings, counts, rank and own skins are kept
- About a minute: the widget restarts and this page reloads itself
- **This one time only:** if the path to the widget folder has non-Latin letters, & or %, it may not start on its own. Download widget-stats.exe from GitHub and replace the old file with it. Your settings are kept, and later updates will go through on their own
