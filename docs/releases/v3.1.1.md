# v3.1.1 — свои шрифты

Загрузите любой шрифт — например, Furore — и он появится в виджете

### Что нового

- **Свои шрифты.** В «Цвета и шрифт» → «Шрифт и иконки» появился блок «Свои шрифты»: перетащите туда файл TTF, OTF, WOFF или WOFF2 или кликните и выберите его. Можно несколько сразу
- Загруженный шрифт сразу выбирается и показывается в превью и в OBS. В списке шрифтов он помечен «(свой)»
- Шрифты хранятся в папке программы и работают без интернета — в отличие от Google-шрифтов, которым нужна сеть
- Каждый загруженный шрифт виден плашкой своим начертанием; крестик удаляет его. Если удалённый шрифт был выбран, виджет вернётся на Arial
- Если загрузить шрифт с тем же именем ещё раз, старый файл заменится

### Что будет при обновлении

- Настройки, счёт, ранг и свои скины сохранятся
- Около минуты: виджет перезапустится, страница обновится сама

---

## English

Upload any font — Furore, for example — and use it in the widget

### What's new

- **Your own fonts.** Colours & font → Font and icons has a new "Your fonts" box: drop a TTF, OTF, WOFF or WOFF2 file there, or click to pick one. Several at once work too
- An uploaded font is selected right away and shows in the preview and in OBS. The font list marks it "(yours)"
- Fonts are kept in the app folder and work offline — unlike Google fonts, which need the internet
- Each uploaded font shows as a chip in its own typeface; the cross deletes it. If the deleted font was selected, the widget falls back to Arial
- Uploading a font with the same name again replaces the old file

### What happens when you update

- Your settings, counts, rank and own skins are kept
- About a minute: the widget restarts and this page reloads itself
