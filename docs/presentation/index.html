Возможности

Что умеет виджет

Автозачёт и автоматический ранг В Overwatch 2 победа, поражение и ранг считаются сами: виджет читает экран игры. Ничего настраивать не нужно — включается одной галочкой в разделе «Автозачёт».
Удобная админка Новое Живое превью для каждого вида, всё сохраняется само, есть «Отменить». Настройки, которые вид не использует, скрыты.
Сессия стрима Новое Виджет помнит ранг на начало стрима и показывает, на сколько вы поднялись и как прошли последние игры.
Обновление в один клик Новое Админка сама сообщает о новой версии и ещё до обновления показывает, что изменится.
Помощь простыми словами Новое Справка с поиском прямо в админке и кнопка «Написать разработчику».
Без мерцания Обновления по WebSocket — Browser Source в OBS не перезагружается.
Скрипт для OBS Виджет запускается вместе с OBS, горячие клавиши работают без лишних окон.
Stream Deck и Stream Dock Win, Loss и ранг на кнопках деки. LIVE-пак показывает счёт и ранг прямо на кнопках.

Установка

Установка за несколько минут

1

Создайте папку для виджета

Создайте отдельную папку — туда скачаете widget-stats.exe и widget_control.lua. Если при скачивании Windows Defender ругается, добавьте эту папку в исключения: у виджета нет сертификата Microsoft.

2

Скачайте с GitHub

Откройте Releases и скачайте оба файла в созданную папку.

Страница Releases →
3

Подключите Lua-скрипт в OBS

Tools → Scripts → «+» → выберите widget_control.lua из папки с exe. Сервер запустится вместе с OBS.

4

Откройте админку

Иконка в трее → Open Admin. Здесь настраивается всё: вид, скины и подключение к OBS.

5

Включите WebSocket в OBS

Tools → WebSocket Server Settings → Enable. Порт по умолчанию — 4455.

6

Поставьте виджет на сцену

В админке: «Подключения» → «Подключить OBS» → выберите сцену → «Поставить виджет на сцену». Установка готова.

Настройка

Под себя

После установки: вид, скин, цвета и горячие клавиши.

1

Выберите вид

Админка → «Вид виджета» → нажмите на любой. Превью справа сразу показывает, как он реагирует на победу и смену ранга. Сохраняется само.

2

Подберите скин

«Скины» → наведите на скин, и превью покажет ваш виджет в нём. Клик — применить. Есть поиск, подборки по настроению и избранное.

3

Цвета, шрифт и анимации

«Цвета и шрифт» и «Анимации» — меняйте что угодно, превью обновляется сразу. Передумали — «Отменить» внизу экрана.

4

Горячие клавиши в OBS

File → Settings → Hotkeys. Назначьте Win, Loss и Rank — статистика обновляется одним нажатием на стриме.

Stream Deck и аналоги

Те же действия можно повесить на кнопки деки. Ссылки копируются в админке: «Подключения» → «URL для OBS / Stream Deck».

Плагин нужен не всем. Если у вас Stream Dock от AJAZZ — поставьте HTTP-плагин. Есть классические иконки и LIVE-пак (цифры побед/поражений и код ранга на кнопках).
