Установка

Поставить самому

Где нужен экран — скрин или короткое видео. Lua — сразу после скачивания, он сам поднимет сервер.

1

Скачай релиз

Скачай widget-stats.exe и widget_control.lua из Releases — оба файла, в одну папку.

Открыть Releases →
2

Сразу добавь Lua-скрипт

Первым делом: OBS → Tools → Scripts → «+» → widget_control.lua (рядом с exe). Скрипт сам запустит сервер при старте OBS и остановит при закрытии.

3

SmartScreen — это нормально

При первом запуске exe Windows может предупредить. Подробнее → Выполнить в любом случае. Код открыт в репозитории.

4

Открой админку

Иконка в трее → Open Admin (или http://127.0.0.1:19123/admin/). Сервер уже должен быть запущен скриптом.

5

Включи WebSocket в OBS

Tools → WebSocket Server Settings → Enable, порт 4455.

6

Поставь виджет на сцену

В админке: Подключить OBS → сцена → Поставить виджет на сцену.
