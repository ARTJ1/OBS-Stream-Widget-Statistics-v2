# Сценарий медиа для установки

Порядок в гайде:

1. Скачать exe + lua  
2. **Lua в OBS** (сразу — сам поднимет сервер)  
3. SmartScreen  
4. Админка из трея  
5. WebSocket  
6. Поставить на сцену  

Папка: `docs/presentation/assets/`

| Файл | Тип | Шаг |
|------|-----|-----|
| `install-lua.webm` / `.png` | клип или скрин | 2 — Scripts → добавить lua |
| `install-smartscreen.webm` / `.png` | клип или скрин | 3 — SmartScreen |
| `install-tray.png` (лучше скрин) | скрин | 4 — трей → Open Admin |
| `install-obs-websocket.webm` / `.png` | клип или скрин | 5 — WebSocket |
| `install-place-scene.webm` / `.png` | клип | 6 — поставить на сцену |

Крупный кроп, webm без звука 3–6 с. `10-skins-gallery.webm` не нужен.
