# Сценарий WebM

## Установка

1. Папка + Defender → `adding the sv folder is an exception.webm`
2. Скачать → `install-download.webm`
3. Lua → `install-lua.webm`
4. Трей → `install-tray.webm`
5. WebSocket → `install-obs-websocket.webm`
6. На сцену → `install-place-scene.webm`

SmartScreen не снимаем.

## Настройка

1. **Горячие клавиши** → `07-stats-win-loss-rank.webm` (или переименуй в `setup-hotkeys.webm`)  
   Назначение Win/Loss/Rank и реакция виджета.
2. **Внешний вид** → `appearance.webm`
3. **Скины** → `10-skins-gallery.webm` (или `setup-skins.webm`)  
   Вкладка Скины → клик по пресетам.

Крупный кроп, 3–6 с, без звука. На сайте — без таймлайна, автостарт.
