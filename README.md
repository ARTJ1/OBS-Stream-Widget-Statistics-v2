# OBS Stream Widget Statistics v2

Новая версия оверлея статистики (победы / поражения / ранг) для OBS.

## Цели v2

- Обновление статистики **без перезагрузки** Browser Source
- Локальный сервер с автозапуском при старте OBS
- Совместимость со Stream Deck, Bitfocus Companion и аналогами
- Расширенные настройки и скины через веб-админку

## Статус

Проект в стадии проектирования. v1 (file:// + Lua) остаётся отдельно.
